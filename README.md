# GitHub Recapped

## Gives a Recap of your github profile!
## Setup
- Clone the repo and go into it
```
git clone https://github.com/dorkishguy/githubRecapped.git && cd githubRecapped
```
- Run '''main.py'''
'''
python main.py
'''

- Input your username

- Get your stats!
